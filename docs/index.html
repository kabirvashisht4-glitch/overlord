▚ Overlord

It doesn't type.
It does things.

A voice agent that lives on your Mac. Say its name and it opens apps, plays music, changes settings, or hands your question to Claude or Gemini. No cloud service listening in — the transcription happens on your laptop.

The distinction

Dictation gives you text. This gives you actions.

Every voice tool on your Mac converts speech into characters and types them into whatever window has focus. Useful — but the computer never actually does anything.

Dictation

You say "open Spotify" → the words open Spotify appear in your editor.

Overlord

You say "open Spotify" → Spotify opens.

How it works

Four layers. Swap any one.

Each stage talks to the next through a small, boring interface, so replacing one never touches the others.

EarsListenmic → text
BrainRoutetext → call
HandsActrun it
MouthReplyspeak

The interesting part is the brain. It never parses English. It hands the model a list of functions and their schemas, and the model replies with a structured call — so the infinite ways a person can phrase something become the model's problem instead of an endless chain of if-statements.

// you said: "yo can you fire up spotify for me"
{ name: "open_app", input: { app_name: "Spotify" } }
Extending it

A new skill is one file.

Drop a file in src/actions/. The registry finds it at boot — the router and the main loop are never edited.

export default {
  name: "open_url",
  description:
    "Open a website in the browser. Use for 'open github'," +
    " 'go to twitter', 'pull up my linkedin'.",
  input_schema: {
    type: "object",
    properties: { url: { type: "string" } },
    required: ["url"],
  },
  async run({ url }) {
    await run("open", [url]);
    return `Opening ${url}`;
  },
};

The description is not a comment. It's the only thing the model reads when deciding whether to use your action — write it like a signature a stranger has to understand.

Running it

Start with no keys at all.

  1. See the machine turnnpm run dry — mock brain, no network, no API key. Type commands and watch the pipeline work.
  2. Add the voicebrew install sox whisper-cpp, download a model, then npm run wake:dry — real mic, real transcription, still no key.
  3. Give it a real brainPut an Anthropic key in .env and run npm start. Now say "Overlord, open Spotify."
  4. When it mishears younpm run tune reports what every stage actually saw — mic level, transcript, wake-word score — because otherwise a failure just looks like silence.
Privacy

Always-on is not just a convenience change.

Push-to-talk uploads audio when you press a key — you consented, once, per command. A wake word listens forever. Sending that to a cloud transcriber would stream your whole room to someone's server, and nobody else in it agreed to that.

So wake mode defaults to WHISPER_MODE=local. whisper.cpp runs on your laptop and the audio never leaves it. The cloud API stays available, opt-in.
